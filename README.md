HealthConnect Clinic — Week 7 Data Analytics
Project Overview

This repository contains the Week 7 Data Analytics work for the HealthConnect Clinic Support Using Data and AI project.

The focus of Week 7 was to test, refine and validate the Data Analytics outputs developed during Week 6. The testing focused on the accuracy of key no-show metrics, dashboard results and important analytical findings.

Week 7 Objectives
Validate the overall patient no-show rate.
Test key analytical findings from Week 6.
Compare Power BI results with independently validated Excel calculations.
Refine the Power BI dashboard where required.
Document testing evidence and validation results.
Support the wider project objective of reducing missed appointments and improving patient support.
Key Analysis Areas

The Week 7 testing covered:

Overall no-show rate
No-show rate by age group
Reminder sent versus no reminder
Booking lead time and reminder status
Previous no-show history
Power BI dashboard validation
Key Validated Result

The overall no-show rate was validated at 48.46% across the 5,000 appointment records analysed.

The analysis also showed that no-show rates varied across booking lead-time groups, reminder status and previous no-show history. These findings were treated as associations rather than evidence of causation.

Testing and Validation

The Week 7 Power BI dashboard was tested against independently validated Excel calculations. Dashboard interactions were also tested by selecting different categories and confirming that the KPI cards and visuals responded appropriately.

Screenshots documenting the testing and new dashboard changes are included in the Testing Evidence file.

Project Context

HealthConnect Clinic is a fictional clinic scenario used for the project. The overall project explores how data and AI can be used to reduce missed appointments and improve the patient support experience.

The Data Analytics work provides validated insights that can support the wider project and inform further data science and AI development.

Note

The analysis identifies patterns and associations in the available appointment data. The findings should not be interpreted as proof that one factor directly causes a patient to miss an appointment.
